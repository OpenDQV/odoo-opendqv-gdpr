# odoo-opendqv-gdpr

Odoo 17.0 module — GDPR Article 30 Record of Processing Activities (ROPA), enforced at the point of write by [OpenDQV](https://github.com/OpenDQV/OpenDQV).

## Install

1. Copy `odoo_opendqv_gdpr/` into your Odoo addons directory
2. `pip install opendqv>=1.4.0`
3. Install in Odoo: **Settings → Apps → Search "OpenDQV GDPR"**
4. `export ENABLE_OPENDQV_VALIDATION=true`
